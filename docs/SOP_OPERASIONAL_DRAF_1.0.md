# NAM DMS — Draf SOP, checklist dan lampiran laporan

Versi 1.0-draf · 20 Oktober 2026 · demo lokal / data fiktif.
Belum disahkan. Tidak mengganti protokol klinis, QC, verifikasi pembayaran atau persetujuan pasien.

## Cara memakai
Pilih SOP → isi hasil aktual → catat temuan/tindakan/PJ/tenggat → unggah bukti ke item → ajukan → ditinjau petugas lain atau dikembalikan. Riwayat dipertahankan.
Bukti: PDF, PNG, JPG, TXT; 3 MB per berkas, 8 berkas / 15 MB aktif per laporan.
